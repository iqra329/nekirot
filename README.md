# NekiRot Quetta

NekiRot is a food-rescue platform for Quetta, Pakistan. It connects food donors with recipient organizations and riders so surplus food can be listed, matched, collected, delivered, and tracked. The platform aims to reduce food waste and help communities in need.

## Live Demo

🌐 **Visit Live Website:** [http://nekirot.site.je](http://nekirot.site.je)

## Project Goals

- Reduce food waste by making surplus food available to people who need it
- Help donors publish food listings with quantity, deadline, location, and dietary details
- Let recipients find and accept suitable nearby listings
- Match rescues with nearby riders and support pickup-to-delivery status tracking
- Provide live location information and alerts during a rescue
- Recognize community participation with Neki Score and leaderboard features

## Main User Roles

### Donor
Restaurants, hotels, wedding halls, supermarkets, and individuals can publish food listings, provide pickup details, and monitor rescue progress.

### Recipient
Orphanages, madrassas, shelters, and community centers can maintain their location, browse available food, and request rescues.

### Rider
Riders can set their location and vehicle details, view nearby rescues, accept deliveries, share live location, and complete deliveries.

## Core Workflow

1. Donor creates a food listing with pickup deadline and location
2. System shows available listings to nearby recipients
3. Recipient accepts a listing and creates a rescue request
4. Nearby riders receive alerts and accept the rescue
5. Rider picks up food, starts transit, and updates delivery status
6. Location updates and map views help participants follow the rescue
7. Rescue and listing are marked delivered or completed

## Features

- User registration, login, and session-based authentication
- Separate donor, recipient, and rider dashboards
- Food listing creation, editing, viewing, and deletion
- Rescue creation, assignment, acceptance, pickup, transit, and completion
- Rider location updates and GPS simulation tools
- Live map tracking with Leaflet and OpenStreetMap
- Alerts, statistics, delivery history, and Neki Score
- Image uploads for food listings
- Responsive Bootstrap 5 design
- Leaderboard for community recognition
